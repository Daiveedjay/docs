Iris Code installs in four ways: directly from the VS Code Marketplace for automatic updates, as a `.vsix` file for manual installation in any VS Code-compatible editor, from the JetBrains Marketplace for IntelliJ IDEA and the other JetBrains IDEs, or as a global npm package for terminal and CI use. Most users should start with their editor's marketplace - it handles updates automatically and requires no extra steps. If your editor isn't connected to a marketplace, or you need a specific version, use the `.vsix` route. Install the CLI separately whenever you want to run scans and gates outside the editor.

Every host runs the same analysis engine, so a file scores identically in each one, and a single sign-in is shared between your editors and the CLI.

## VS Code Marketplace (Preferred)

The Marketplace install gives you automatic updates and the simplest setup path. Listing: [marketplace.visualstudio.com/items?itemName=davidjaja.iris-code](https://marketplace.visualstudio.com/items?itemName=davidjaja.iris-code).

<Steps>
  <Step title="Open the Extensions panel">
    Press `Ctrl+Shift+X` on Windows/Linux or `Cmd+Shift+X` on macOS to open the Extensions panel in VS Code.
  </Step>
  <Step title="Search for Iris Code">
    Type **Iris Code** in the search box. Look for the extension published by **davidjaja**.
  </Step>
  <Step title="Install the extension">
    Click **Install**. VS Code downloads and activates the extension immediately - no restart required.
  </Step>
  <Step title="Confirm the install">
    The Iris Code icon appears in the Activity Bar. Open any `.js`, `.jsx`, `.ts`, `.tsx`, `.go`, or `.py` file - the Iris Code sidebar populates instantly with no configuration required.
  </Step>
</Steps>

## Open VSX (Cursor, Windsurf, VSCodium, Trae)

These editors read the [Open VSX](https://open-vsx.org/extension/davidjaja/iris-code) registry rather than the VS Code Marketplace, and Iris Code publishes the **byte-identical build** to both. So the in-editor install works exactly as it does in VS Code, and updates arrive automatically.

<Steps>
  <Step title="Open the Extensions panel">
    Press `Ctrl+Shift+X` on Windows/Linux or `Cmd+Shift+X` on macOS.
  </Step>
  <Step title="Search for Iris Code">
    Type **Iris Code** and look for the extension published by **davidjaja**.
  </Step>
  <Step title="Install">
    Click **Install**. No restart required, and no `.vsix` to manage by hand.
  </Step>
</Steps>

<Note>
  You do not need the manual `.vsix` route for these editors. Use it only if your environment cannot reach a registry at all.
</Note>

## Manual VSIX Install

Download the `.vsix` and install it yourself when your environment has no registry access, for example an air-gapped or locked-down machine.

**Download URL:** [`https://www.iriscode.co/downloads/iris-code.vsix`](https://www.iriscode.co/downloads/iris-code.vsix)

Once you have the file, install it using your editor's GUI or the command line:

**Via the GUI (works in all editors):**

1. Open the Extensions panel (`Ctrl+Shift+X` / `Cmd+Shift+X`)
2. Click the **⋯** menu at the top right of the panel
3. Select **Install from VSIX...** and choose the downloaded file

**Via the command line:**

<Tabs>
  <Tab title="VS Code">
    ```bash
    code --install-extension iris-code.vsix
    ```
  </Tab>
  <Tab title="Cursor">
    ```bash
    cursor --install-extension iris-code.vsix
    ```
  </Tab>
  <Tab title="Windsurf">
    ```bash
    windsurf --install-extension iris-code.vsix
    ```
  </Tab>
  <Tab title="VSCodium">
    ```bash
    codium --install-extension iris-code.vsix
    ```
  </Tab>
</Tabs>

<Warning>
  Manual VSIX installs do not auto-update. When a new version of Iris Code is released, you need to re-download the `.vsix` file from `iriscode.co/downloads/iris-code.vsix` and re-install it using the same steps above.
</Warning>

## JetBrains IDEs

Iris Code runs in IntelliJ IDEA, WebStorm, PyCharm, GoLand, PhpStorm, Rider, RubyMine, CLion, and Android Studio. Listing: [plugins.jetbrains.com/plugin/33168-iris-code](https://plugins.jetbrains.com/plugin/33168-iris-code).

<Steps>
  <Step title="Install LSP4IJ first">
    Open **Settings → Plugins → Marketplace**, search for **LSP4IJ**, and install it. Iris Code uses it to talk to its analysis engine. If you install Iris Code from disk rather than the Marketplace, dependencies are not pulled automatically and Iris Code will not load without LSP4IJ.
  </Step>
  <Step title="Install Iris Code">
    In the same **Marketplace** tab, search for **Iris Code** and click **Install**.
  </Step>
  <Step title="Restart the IDE">
    Use a full restart, not a plugin reload. JetBrains registers file-type associations at startup, so a reload leaves `.irisconfig.json` handled incorrectly.
  </Step>
  <Step title="Confirm the install">
    Open any `.js`, `.jsx`, `.ts`, `.tsx`, `.go`, or `.py` file - findings appear as squiggles, and the **Iris Code** tool window on the right shows the full panel. Sign in from **Tools → Iris Code → Sign In**.
  </Step>
</Steps>

### JSON standard does not allow comments

`.irisconfig.json` is JSONC - the presets Iris Code generates are commented so each setting explains itself. Iris Code registers the file with the IDE's JSON5 file type so those comments are valid. If you see this error anyway, your IDE is holding a user-level override that cancels the plugin's registration.

This happens when a plugin that contributes a file-type mapping is uninstalled - updating Iris Code by uninstalling and reinstalling is enough to trigger it. The override lives in your IDE settings rather than in the plugin, so **reinstalling, updating, or restarting will not clear it**.

<Steps>
  <Step title="Open the file type settings">
    Go to **Settings → Editor → File Types**.
  </Step>
  <Step title="Select JSON5">
    Choose **JSON5** in the **Recognized File Types** list.
  </Step>
  <Step title="Add the pattern back">
    In **File name patterns** below, click **+**, enter `.irisconfig.json`, then click **OK** and **Apply**. If the IDE warns that the pattern was previously removed, accept it - that is the override being cleared. No restart is needed.
  </Step>
</Steps>

<Note>
  Prefer editing the file directly? Close the IDE completely, remove the line `<removed_mapping pattern=".irisconfig.json" approved="true" type="JSON5" />` from `filetypes.xml` in your IDE's configuration directory, then reopen. A running IDE rewrites that file when it exits, so the IDE must be closed first.
</Note>

<Warning>
  Do not fix this under **Settings → Languages & Frameworks → Schemas and DTDs**. That screen maps JSON *schemas* to files and its version dropdown lists schema drafts, not file types - JSON5 never appears there. Iris Code configs already carry a `$schema` line, so schema mapping needs no manual entry.
</Warning>

## CLI Install

The Iris Code CLI lets you scan files, run enforcement gates, audit dependencies, and aggregate TODOs from any terminal or CI pipeline - no VS Code required.

Install it globally with npm:

```bash
npm install -g @iris-code/cli
```

Verify the installation:

```bash
iris --version
```

<Note>
  The CLI requires **Node.js 18 or later**. Run `node --version` to check. If you need to upgrade Node, visit [nodejs.org](https://nodejs.org) or use a version manager like `nvm`.
</Note>

## System Requirements

| Component | Requirement |
|---|---|
| **VS Code** | Version 1.85 or later |
| **Compatible editors** | Cursor, Windsurf, VSCodium (any VS Code-compatible editor) |
| **JetBrains IDEs** | 2024.2 or later, plus the LSP4IJ plugin |
| **Node.js (CLI only)** | Version 18 or later |
| **Operating system** | Windows, macOS, Linux |

**Supported languages:**

- TypeScript - `.ts`, `.tsx`
- JavaScript - `.js`, `.jsx`, `.mjs`, `.cjs`
- Go - `.go`
- Python - `.py`

No additional language servers, compilers, or runtimes are required for the extension. Iris Code analyses your files in-process using its own static analysis engine.
