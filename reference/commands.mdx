This page lists Iris Code commands you can run from your editor. Open the command palette with <kbd>Ctrl+Shift+P</kbd>, or <kbd>Cmd+Shift+P</kbd> on macOS, then type `Iris Code` to find an action. Some commands also appear when you right-click a file or folder.

<Note>
  Looking for the terminal commands instead? Those are in the [CLI reference](/cli/commands). This page is the editor.
</Note>

## In the command palette

| Command | Description |
|---|---|
| `Iris Code: Scan Current File` | Manually re-scan the active file |
| `Iris Code: Scan Workspace` | Scan all JS/TS/Vue/Svelte/Go/Python/Ruby/C#/Java/Rust files in the workspace |
| `Iris Code: Rescan Everything` | Scan the workspace again, analysing every file rather than reusing unchanged results |
| `Iris Code: Scan This File` | Right-click a file in Explorer to scan it |
| `Iris Code: Scan This Folder` | Right-click a folder in Explorer to scan it |
| `Iris Code: Scan Current Folder` | Scan the folder of the currently open file |
| `Iris Code: Open in Panel` | Pop the sidebar out into a full editor panel beside your code |
| `Iris Code: Open Code Map` | Open the health tree and import graph, with [map exports](/features/code-map#exporting-the-map) |
| `Iris Code: Export Scan Report as HTML` | Save the current analysis as a standalone HTML report |
| `Iris Code: Install Git Hook` | Install the pre-push hook. Follows Git's `core.hooksPath`, so a Husky project gets `.husky/pre-push` |
| `Iris Code: Uninstall Git Hook` | Remove the Iris Code block from the pre-push hook |
| `Iris Code: Install Build Hook` | Wire Iris Code scans into the project build - `prebuild` for Node, Makefile target for Go, Python, Ruby, and .NET |
| `Iris Code: Uninstall Build Hook` | Remove the Iris Code build hook, leaving any other build steps intact |
| `Iris Code: Write Project Rules for AI Agents` | Generate this project's rules into `AGENTS.md`, `CLAUDE.md`, a Cursor rule, or Copilot instructions |
| `Iris Code: Open Config Studio` | Open the browser Config Studio to build or edit `.irisconfig.json` |
| `Iris Code: Open Dependents Table` | Open the dependency audit panel (versions + CVEs) |
| `Iris Code: Show Welcome Page` | Open the Getting Started welcome page |
| `Iris Code: Review My Changes` | Scan staged, unstaged and untracked changes, with direct import impact. Free |
| `Iris Code: Select Workspace Folder to Scan` | Choose which folder a multi-root workspace scan covers |
| `Iris Code: Restart First Scan` | Restart the first-scan onboarding flow |
| `Iris Code: Sign In` | Sign in through the browser and refresh the editor licence |
| `Iris Code: Sign Out` | Sign out of the editor; remembered organisation restrictions remain |
| `Iris Code: Check License Status` | Refresh and show the current licence status |
| `Iris Code: Sync Config from Dashboard` | Use a dashboard code to preview and confirm a shared config |
| `Iris Code: Open Trends Table` | Open saved health-score snapshots. Free retains two; Pro retains all |
| `Iris Code: Lock Trend Baseline` | Use the current workspace snapshot as the trend baseline |
| `Iris Code: Clear Trend History` | Remove the current workspace trend history after confirmation |
| `Iris Code: Close Panel` | Close the detached editor panel |
| `Iris Code: Add GitHub Actions Workflow` | Generate the Iris Code GitHub Actions workflow |
| `Iris Code: Add CI Pipeline Snippet` | Generate a pipeline snippet for another supported CI provider |
| `Iris Code: Scan Git History for Secrets` | Scan Git history for leaked credentials. Pro |
| `Iris Code: Check Packages Before Agents Install Them` | Choose coding agents and install the free package guard hook |
| `Iris Code: Remove the Package Guard Hook` | Remove the package guard entries while preserving other hooks |
| `Iris Code: Rename File to Naming Convention` | Preview and rename one file to its configured naming convention |
| `Iris Code: Undo Last Rename` | Undo the last naming-convention rename |
| `Iris Code: Dependency Network Access` | Manage consent for registry and advisory lookups |

The [Refactor playbook](/refactor/overview) opens from **Refactor plan** in the File, Folder or Workspace tab. Its panel provides **Get plan**, **Apply mechanical fixes**, **Open agent instructions** and **Verify refactor**.

## Context menus

Iris Code adds entries to the right-click menu in two places in the VS Code interface.

### Explorer (file tree)

Right-clicking inside the Explorer panel exposes file- and folder-scoped commands without requiring you to open the file first:

- Right-click a **JS/TS/Vue/Svelte/Go/Python/Ruby/C#/Java/Rust file** → **Iris Code: Scan This File**
- Right-click a **folder** → **Iris Code: Scan This Folder**
- Right-click **anywhere** in the Explorer → **Iris Code: Scan Workspace**

### Editor (inside a file)

Right-clicking inside an open file gives you analysis commands scoped to the current file or its containing folder:

- **Iris Code: Scan Current File** - re-run analysis on the file you are editing
- **Iris Code: Scan Current Folder** - scan all supported files in the same folder
- **Iris Code: Scan Workspace** - run a full workspace scan from the editor context menu
