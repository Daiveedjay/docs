Not every refactor suggestion is available in every language. Use this table to check what Iris Code can suggest for your files and where a change still needs to be handled without a suggestion.

## Coverage

The table uses three labels:

- **`built`**: Iris Code can offer this suggestion in the language. You still need to review it and test the change.
- **`left-out`**: Iris Code does not offer this suggestion in the language.
- **`not-applicable`**: the language or kind of file does not have the feature this suggestion needs.

TypeScript and JavaScript component suggestions need JSX or TSX component code. They do not apply to ordinary files. Vue and Svelte use their own component structure.

Even a `built` suggestion may be left out of a particular plan when Iris Code cannot clearly identify the code to change.

## Omissions and review

Every `left-out` cell above has a measured reason, which each plan reports in its coverage for that language. The table below explains the omissions that are most often asked about.

| Suggestion | Language | Reason |
|---|---|---|
| `lookup-table` | Ruby and Rust | Class/pattern arms, payload bindings and guards are not scalar lookup entries |
| `move-imports-with-code` | Ruby | Require statements do not identify imported bindings, so exclusive use cannot be proved |
| `name-magic-numbers` | Ruby and Svelte | Opcode data and chart observations already carry domain meaning |
| `extract-function` | Java | Small early-exit guards in large files exceeded the review threshold |
| `move-types` | JavaScript and Ruby | No separate type-declaration syntax; classes use split-declarations |
| State/effect/component suggestions | Non-component source | These suggestions need React JSX, Vue or Svelte component code |

The review threshold removes a suggestion from a language when more than one in ten observed suggestions is definite nonsense. The [generated review evidence](/trust/accuracy-benchmark#refactor-suggestion-evidence) records observations and omissions from a review of 200 plans across the ten languages. No overall suggestion accuracy is claimed.
