The [Iris Code Playground](https://www.iriscode.co/playground) lets you see what Iris Code does before you install anything. It opens a small sample project in your browser that already contains realistic problems: a password-like secret written into the code, a database query built by joining strings together, duplicated logic and a file named against the project's convention.

The Playground runs the same checks Iris Code uses everywhere else, from the `@iris-code/core` package, and the same gate that decides whether code passes. Only the Git push is pretend. The score, the findings and the pass or block decision are real.

## Try the loop

1. Open the Playground in a browser on a laptop or desktop computer.
2. Start from the welcome screen, then go straight into the sample project or follow the guided tour.
3. Read the findings in the Iris Code panel, then edit the files or `.irisconfig.json`, the project's settings file. The checks run in your browser as you edit.
4. Run the pretend push from the Playground's terminal. Fix the findings and push again to see the result change.

## What stays private

Your code stays in the browser tab. The Playground does not upload source code, file paths, source hashes (fingerprints of file contents) or project structure.

It records a few anonymous daily counts, such as how often the demo was opened, code was pasted, a scan ran after an edit, a push was tried and the install button was clicked. These counts contain nothing that identifies a visitor or a visit, so they cannot be joined together to follow one person through the steps.

## What it does not replace

The Playground shows the short loop from editing code to the gate's decision. Install Iris Code for live checks in your editor, whole-project scans, real Git hooks, build checks, CI, dependency audits, settings sync and the full editor integration.
